# 🪝 **RzL-Stealer**

---

## **Um malware Stealer para testes de penetração com persistencia ativa.**

---

## ✨ **Funcionalidades Principais**

Este projeto é um malware desenvolvido para fins de estudo e testes controlados.

Possui persistência contra reboot e perca de conexão de internet e captura informações como:

- 🦠 **Informações de antivírus**
- 📃 **Histórico de navegação**
- 💳 **Cartões**
- 🍪 **Cookies**
- 👤 **Contas do Discord**
- ⬇️ **Histórico de downloads**
- 🧩 **Extensões de navegadores**
- 🔑 **Senhas salvas**
- 👝 **Carteiras de Criptomoedas**
- 👤 **Contas do Roblox**
- ℹ️ **Informações do sistema**

---

## 📡 **Resultados Coletados**

Os resultados coletados são enviados através de um webhook do Discord com um link para o download do arquivo compactado.
